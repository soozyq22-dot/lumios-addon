LumiOS vs. a Smart-Building Vendor

Lumi Nails & Med Spa — capability & value comparison

LumiOS is a complete smart-building control system Lumi already owns. This sheet compares it against what a typical installed-by-a-vendor system (e.g. a Brightstar-style quote) provides — use it to evaluate any proposal before you sign.

Everything LumiOS already does

  • ✔ Lock / unlock doors (auto-lock)
  • ✔ Lights on/off + dimming per zone
  • ✔ Motorized shades per zone
  • ✔ Thermostat per zone + setback
  • ✔ Music per zone + whole-spa audio
  • ✔ Security cameras + motion alerts
  • ✔ Arm / disarm security panel
  • ✔ Scenes: Open · Treatment · Goodnight · Close · Away
  • ✔ Voice control
  • ✔ Schedules + after-hours triggers
  • ✔ Roles: Owner / Manager / Staff
  • ✔ Per-user front-desk PINs
  • ✔ Owner two-factor sign-in
  • ✔ Full audit log (who/what/when)
  • ✔ Energy + UPS backup monitoring
  • ✔ Phone push alerts (installable app)

The one thing a vendor provides that software can't: the physical devices and installation. LumiOS works with any reputable Matter/Zigbee/ONVIF gear, so you choose the hardware and the installer.

What this means for cost

You already own the expensive, recurring part — the control software, with no monthly fee and no lock-in. A vendor quote is mostly hardware + labor, which you can source competitively. Ask any vendor to quote install only, since LumiOS already covers the brains.

Questions to ask before you sign

  1. Open standards, or locked to your brand and app?
  2. Do doors and lights still work if the internet is down?
  3. What's the door fail-safe on power/network loss — and is there a physical key override?
  4. Owner/manager/staff roles with individual PINs?
  5. Is there an audit log of door unlocks?
  6. Do I keep camera footage locally, with no forced cloud subscription?
  7. If I change installers later, do I keep the hub, devices, and footage?
  8. Can you quote installation only (I already have the control system)?
